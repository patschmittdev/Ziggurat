# Support

Ziggurat is a pre-release reference implementation maintained on a best-effort basis.
It does not currently provide commercial support or a hosted service.

## Where to ask

- Use the question issue form for setup, integration, and architecture questions.
- Use the bug report form for reproducible defects.
- Use the proposal form for changes to behavior, formats, or trust boundaries.
- Follow [SECURITY.md](SECURITY.md) for suspected vulnerabilities. Do not include
  vulnerability details, credentials, private keys, or private vault content in a
  public issue.

Before opening an issue, search existing issues and include the smallest fictional
example that reproduces the problem. The project clean-room rules prohibit private
vault data in reports and test fixtures.
